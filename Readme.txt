====================================
AI ART JUDGE - AIお絵描き判定ゲーム
====================================

このゲームは、プレイヤーが描いた絵をGoogleの最新AI（Gemini 2.5 Flash）が視覚的に認識し、
「何を描いたか」を判定して辛口/甘口なコメントをくれる新感覚お絵描きゲームです。

■ 動作環境
------------------------------------
- Linux (Rocky Linux 8.10等 / KIC環境想定)
- Raylib 5.0以上

■ コンパイル方法
------------------------------------
ターミナルで以下のコマンドを実行してください。

1. 必要なライブラリのインストール（初回のみ）
   sudo dnf install -y git make gcc libcurl-devel alsa-lib-devel mesa-libGL-devel libX11-devel libXrandr-devel libXinerama-devel libXcursor-devel libXi-devel

2. Raylibのインストール（未インストールの場合）
   git clone https://github.com/raysan5/raylib.git raylib_src
   cd raylib_src/src
   make
   sudo make install
   cd ../..

3. ゲームのコンパイル
   make

   ※ エラーが出ずに `draw_game` というファイルが生成されれば成功です。

■ ゲームのやり方
------------------------------------
1. APIキーの設定（必須）
   このゲームはAIを使用するため、Google GeminiのAPIキーが必要です。
   以下のコマンドでAPIキーを設定してから実行してください。

   export GEMINI_API_KEY="あなたのAPIキー"

2. ゲームの起動
   ./draw_game

3. 操作方法
   [タイトル画面]
   - SPACEキー: ゲームスタート

   [お絵描き画面]
   - 左クリックドラッグ: 絵を描く
   - マウスホイール: ブラシの太さを変更
   - Cキー: キャンバスを白紙に戻す

   [結果画面・ゲームオーバー]
   - SPACEキー: タイトルに戻る

■ 工夫したところ・アピールポイント
------------------------------------
1. 生成AIとのリアルタイム対話
   単に「正解/不正解」を出すだけでなく、AIが「これは〇〇に見えますね」や
   「もっと特徴を捉えてください！」といった、人間味のあるコメントを返します。
   毎回違うコメントが返ってくるので、何度でも楽しめます。

2. レトロポップなUIデザイン
   黄色と黒を基調とした、視認性が高く元気な印象を与えるデザインに仕上げました。
   Ankobinary氏のキャラクター画像や、吹き出しによるメッセージ表示など、
   「ゲームらしさ」を意識したUI/UXを実装しました。

3. 美しいコード設計
   C言語の標準機能を使いこなしつつ、コメントを極限まで削ぎ落とした
   ミニマリストで美しいコードベースを実現しました。
   可読性をコードの構造そのもので担保しています。

4. 堅牢な通信処理
   libcurlを用いたHTTP通信処理を行い、Base64エンコードを含む
   JSONリクエストの構築をC言語だけでスクラッチ実装しました。
