====================================
AI ART JUDGE - AIお絵描き判定ゲーム
====================================

このゲームはプレイヤーがお題の描いた絵をLLMに画像認識して「何を描いたか」を判定させて、辛口/甘口なコメントをくれる新感覚お絵描きゲームです。
LLMがお題と違った絵と誤認識した場合にゲームが終了となって、その時点のスコアと称号が与えられます。

■ 動作環境
------------------------------------
- Linux (Rocky Linux 8.10等 / KIC環境想定)
- Raylib 5.0以上

■ コンパイル方法
------------------------------------
以下のコマンドを実行してください。

1. ゲームのコンパイル
   make


■ ゲームのやり方
------------------------------------
1. APIキーの設定
   このゲームではLLMを使用するため、Google GeminiのAPIキーが必要です。（お手数おかけして申し訳ないです🙇‍♂️）
   以下のコマンドでAPIキーを設定してから実行してください。（AI studioからAPI keyを取得できます）.

   export GEMINI_API_KEY="APIキー"

2. ゲームの起動
   ./draw_game

3. 操作方法
   [タイトル画面]
   - SPACEキー: ゲームスタート

   [お絵描き画面]
   - 左クリックドラッグ: 絵を描く
   - マウスホイール: ブラシの太さを変更
   - Cキー: キャンバスを白紙に戻す

   [結果画面・ゲームオーバー]
   - SPACEキー: タイトルに戻る

■ 工夫したところ・アピールポイント
------------------------------------
1. 生成AIとのリアルタイム対話
   従来のようなゲームとは違ってLLMを使用することによってより抽象的な絵でも判定することができるようになりました（アルゴリズムベースだとできない）
   またLLMにコメントを出力させることで何回でも異なる結果を楽しむことができます。
   またAIと対話しながらお絵描きができるゲームになっています。

2. UIデザイン
   お絵描きゲームとして独特のUIデザインを考えました。
   例えば背景画像やLLMによるコメントの吹き出しによる表示や、キャンバスのデザインを工夫しました。
   昔のゲームのようなレトロなフォントとUIにしました。
   

3. コード設計
    ファイルを分けて階層化することで可読性を高めました。
